# Luma — strona wydania

Publiczna strona informacyjna i źródło manifestu aktualizacji dla aplikacji Luma na macOS.

Strona jest publikowana z katalogu `site/` przez GitHub Actions. Po opublikowaniu nowego instalatora zaktualizuj `site/latest.json`.

Aplikacja Luma jest dystrybuowana osobno; to repozytorium zawiera wyłącznie stronę i pliki wydania.
